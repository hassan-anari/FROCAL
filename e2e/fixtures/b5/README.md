# Photographic Network avatar regression asset

`community-photo.png` is the public-domain NASA photograph of astronaut Eileen Collins, distributed by scikit-image as `astronaut.png`:
https://github.com/scikit-image/scikit-image/blob/v0.21.0/skimage/data/astronaut.png

Unmodified photo bytes; used locally as a real photographic avatar to inspect rounded photo edges. It is not an actual owner's Telegram group, production user data, or a B5 backend fixture. Empty and HTTP-failure avatar cases use the existing B3/B4 group response schema in the browser test.
