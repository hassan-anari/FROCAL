# Phase 3 Game Loop

## Earn tab
Daily Core → Mission start → Verification → XP claim → Level progress

## Network tab
Share referral → Referral verification → Tier progress → Add bot to groups → Group verification → Network XP

## Typing tab
Open Typing Arena → Complete a 30-second run → Accuracy/WPM result → Daily history → Up to five runs per day

## Mission states
Available → In progress → Reward ready → Completed

## Typing rules
- 30 seconds
- 85% accuracy threshold
- 10 WPM threshold
- Five completed runs per local day
- Best score persists across days
