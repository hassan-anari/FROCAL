# Clan Frontend Scope

## Status
Phase 4 Profile is closed. Clan frontend v5.0 is now implemented and awaiting user QA.

## Boundary
This stage is frontend-first. Build UI/state flows with mock data. Backend/economy/business calculations are connected later.

## Unlock
- Locked below Level 5.
- At Level 5: permanent one-time choice between Captain and Soldier.
- No role-switch UI.

## Choice explanation
Captain:
- leadership responsibility
- must lead and manage the clan
- clan success depends heavily on Captain decisions

Soldier:
- contributes through actions
- individual performance can materially change clan progress/outcomes

## Soldier before membership
- Clan Leaderboard
- Search
- Suggested/newly-active suitable clans
- Clan preview
- one active Join Request only
- Pending / Accepted / Rejected states

After acceptance, Discovery/Search is removed and Headquarters becomes the main Clan screen.

## Captain
- Create Clan
- Set clan identity
- Headquarters
- Join Request inbox
- Accept / Reject applicants
- Treasury-funded Shop / Inventory purchasing

## Headquarters
- identity
- level + progress
- status
- rank
- Treasury
- members
- member levels
- member clan contribution/score
- active tasks
- completed tasks
- clan achievements
- clan inventory
- recent clan activity/history

## Tasks
Must be separated:
- Group Tasks
- Individual Tasks

## Inventory
Inventory is part of Clan.

Member:
- read-only purchased items

Captain:
- Shop-like purchase UI
- spend Treasury
- item artwork/name
- price
- description
- effect/purpose
- mocked purchase states until backend exists
