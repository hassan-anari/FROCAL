# Base Promo Banner Specification

## Placement
Below the main game header and above the Dexo card.

## Source artwork
- Path: `/assets/banners/base-promo-banner.webp`
- Format: WebP
- Exact size: **1200 × 260 px**
- Aspect ratio: **60:13** (approximately 4.62:1)
- Recommended maximum size: **120 KB**
- Color space: sRGB

## Safe content area
Keep logo, copy and CTA inside the central **1020 × 180 px** area.

## Display
- Full available width inside the Mini App page padding
- Approximately 64–90 px tall depending on the Telegram viewport
- Hidden by default
- Controlled from Diagnostics
- A labeled placeholder appears until the real image exists

No banner artwork is bundled in this checkpoint.
